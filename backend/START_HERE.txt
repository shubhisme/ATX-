HOW TO START
============

1. Start the backend:
   python run.py

   OR

   python start.py


2. In another terminal, monitor workers (optional):
   python monitor_queue.py


3. In another terminal, test it:
   python demo_parallel.py


WHAT YOU'LL SEE
===============

Backend will show:
   🚀 Starting PR Verification Engine...
   🟢 Worker 0 started and waiting for jobs
   🟢 Worker 1 started and waiting for jobs
   🟢 Worker 2 started and waiting for jobs
   ✅ Started 3 async workers


When you submit PRs:
   ✨ PR #1 submitted as job 1 | Queue: 0 | Busy workers: 0/3
   🔴 [Worker 0] Picked up job 1 (Queue size: 0)
   [Worker 0] Processing job 1 (PR #1)
   🟢 [Worker 0] Completed job 1, back to idle

TROUBLESHOOTING
===============

If you get "module not found":
   pip install -r requirements.txt

If port 8000 is busy:
   Edit .env: API_PORT=8001


THE QUEUE SYSTEM
================

✅ Non-blocking submission (returns immediately)
✅ Workers auto-pick jobs from queue
