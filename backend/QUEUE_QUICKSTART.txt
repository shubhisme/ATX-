WHAT IS IT?
-----------
3 async workers process PR jobs in parallel using Python's asyncio.Queue.
Jobs are distributed automatically. Non-blocking submission.


HOW TO TEST (3 Terminals)
--------------------------

Terminal 1: python start.py
Terminal 2: python monitor_queue.py  
Terminal 3: python demo_parallel.py

KEY CONCEPTS
------------

asyncio.Queue()          → Unbounded FIFO queue
await queue.get()        → Worker waits for job (non-blocking)
await queue.put(job_id)  → Add job to queue (instant)
queue.task_done()        → Mark job complete

3 Workers = 3 jobs processing at the same time
